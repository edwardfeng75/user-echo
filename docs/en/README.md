# docs guide

This folder contains the English OpenCode plugin design documents and their preview images.

## Reading Order

1. `uc_user-echo_main.puml`
2. `sd_user-echo.puml`
3. `../images/`

## File Notes

- `uc_user-echo_main.puml`: the main use case diagram for the overall feature scope.
- `sd_user-echo.puml`: the sequence diagram for TUI, event, and panel interactions.
- `images/uc_user-echo_main.png`: preview for the use case diagram.
- `images/sd_user-echo.png`: preview for the sequence diagram.
- `../images/example-01.png`: collapsed UI example.
- `../images/example-02.png`: expanded UI example.

## Update Rules

- After changing a `puml` file, update the matching PNG preview at the same time.
- The public homepage should link to these diagrams and documents first.
