# docs 指引

這個資料夾放繁體中文的 OpenCode plugin 設計文件與對應預覽圖。

## 閱讀順序

1. `uc_user-echo_main.puml`
2. `sd_user-echo.puml`
3. `../images/`

## 檔案說明

- `uc_user-echo_main.puml`：主使用案例圖，描述整體功能邊界。
- `sd_user-echo.puml`：循序圖，描述 TUI、事件與面板的互動流程。
- `images/uc_user-echo_main.png`：使用案例圖預覽。
- `images/sd_user-echo.png`：循序圖預覽。
- `../images/example-01.png`：收合狀態的 UI 範例。
- `../images/example-02.png`：展開狀態的 UI 範例。

## 更新原則

- 修改 puml 後，要同步更新對應 PNG 預覽圖。
- 公開版首頁應優先連結這裡的圖檔與文件。
